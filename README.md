# Для любимой

Небольшой персональный сайт о любви, собранный на React, TanStack Start, Vite и Tailwind CSS.

## Деплой на Vercel

Репозиторий подготовлен для Vercel через Nitro.

1. Откройте новый проект в Vercel и выберите репозиторий `manfnnnnes/kissa`.
2. **Root Directory** оставьте корнем репозитория.
3. Используйте **Node.js 22**.
4. Команду сборки оставьте `npm run build`.
5. Нажмите Deploy.

Для TanStack Start на Vercel используется Nitro. В проекте уже есть `vercel.json`, поэтому Vercel явно получает информацию о фреймворке.

## Переменные окружения

Для самой публичной страницы база данных и авторизация не нужны. Приложение рассчитано на работу без обязательных секретов.

Не добавляйте секреты в переменные с префиксом `VITE_`: такие значения попадают в браузерный код.

## Локальный запуск

```bash
npm ci
npm run dev
```

Проверки:

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## Структура

- `src/routes` — страницы и серверные маршруты TanStack Start.
- `src/components/love` — секции сайта.
- `src/lib/love.ts` — весь текст и данные персональной страницы.
- `public/images` — изображения сайта.
- `vite.config.ts` — Vite + TanStack Start + Nitro.
- `vercel.json` — явная конфигурация Vercel.

## Важно

Сайт работает как обычное приложение TanStack Start. Grok может запускать его в своём предпросмотре, а тот же исходный код можно публиковать на Vercel. Сгенерированные `.vercel/` и `dist/` не являются частью исходников и игнорируются Git.
